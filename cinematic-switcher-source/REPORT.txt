HYPRLAND CINEMATIC DESKTOP SWITCHER
Public source export and publication review

Included
--------
- Current Python renderers for Windows, LeyzS and Serpantinum, the launch
  guard, switch transaction and source for the Qt Wayland layer bridge.
- Start menu, music and Wi-Fi QML popups and their Python helpers.
- Portable replacement Lua profiles and Waybar configurations. The install
  tool generates local monitor and Hyprpaper configuration and original
  fallback wallpapers. Stock Serpantinum and SwayNC are external dependencies.
- Project audio named leyzs.wav and serpantinum.wav, provided as original
  project audio. The files contain no reported personal metadata.
- README.md, .gitignore, the setup/restore entry point and sample monitor input.

Excluded
--------
- Personal backups, legacy configuration and renderer revisions, runtime
  logs, diagnostic captures, screenshots, package/debug binaries, the
  compiled .so, locks, current-theme, caches, private Quickshell snapshots
  and Git history.
- Personal Serpantinum settings, location, avatar, recent files, pinned
  desktop state, passwords, credentials and NetworkManager connections.
  Source code still contains the fields needed to enter Wi-Fi credentials
  at runtime. It contains no saved credentials.
- Microsoft startup recording, Windows wallpapers, logos and app artwork,
  prior wallpaper collections, anime/video/music assets, third-party app
  artwork, and original upstream dotfile presets whose redistribution rights
  could not be established. No asset links automatically download that media.
- The original upstream Serpantinum QML tree and assets. The package is
  installed separately. The music wrapper loads its installed component.
- Machine-specific setup notes and extra app presets. The clean install
  manages Hyprland and Waybar, leaving unrelated app settings alone.

Rights and publication
----------------------
- No top-level LICENSE was assigned. A project-wide licensing grant requires
  confirmation from the rights holder. A public repository or attribution
  alone does not grant redistribution rights.
- Neither L3yzs repository snapshot contained an explicit license. The
  export uses independently prepared portable profiles and Waybar styling
  instead of shipping the upstream presets or assets. README.md credits
  both inspirations. Have the rights holder review any remaining inherited
  code before assigning a project license.
- The installed Serpantinum package identifies its license as AGPL-3.0-only.
  Quickshell and LayerShellQt are separately installed dependencies with
  their own terms. Review obligations for the QML integration before
  distribution. This archive does not carry their binaries or source.
- Confirm ownership of the two included project sound cues before publishing.
  The original Windows recording is excluded. Users can supply a permitted
  recording under the documented optional filename.
- Review references to Windows and other app names for presentation and
  branding. Add only newly captured, redacted screenshots you can publish.

Validation and remaining work
-----------------------------
- Hyprland 0.57.2 accepted the three generated Lua configurations from the
  example monitor fixture. Qt's tools compiled the LayerShellQt bridge and
  generated bytecode for the three popup QML sources.
- Bash and Python parsed successfully. Both Waybar JSON configs and the
  monitor sample parsed. The setup tool decoded the generated PNGs with Qt.
- An isolated HOME test exercised fresh installation, direct switches
  between LeyzS and Windows, preservation of the original config, and
  restoration to the original config. The test used real config validation
  and compilation with mocked compositor IPC and desktop daemons.
- The local package names and Serpantinum package build instructions were
  checked against installed package metadata and official documentation.
  A clean-machine package build, Wayland compositor test, visual timing
  check and interactive Wi-Fi/music test remain to be run before release.
- Manually complete Serpantinum first-run setup, choose wallpaper for every
  active output and configure NetworkManager permissions as appropriate.
  The sample monitor configuration is for dry checks. Live installation
  reads the user's active monitors.
- The existing desktop profiles and live switcher were only read. The
  portable installer and replacements belong to this export.
